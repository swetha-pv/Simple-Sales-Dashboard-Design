# Simple-Sales-Dashboard-Design  

## Objective
Build an interactive dashboard in Tableau to visualize sales by product category, region, and month.

## Tools Used
- Tableau
- Dataset:Sample-Superstore_Sales.csv

## Steps Taken
1. Imported `Sample-Superstore_Sales.csv` into Tableau.
2. Created a calculated field to convert `Order Date` to "Month-Year" format.
3. Built 3 visualizations:
   - Line Chart: Monthly Sales Trend
   - Bar Chart: Sales by Region
   - Bar Chart: Sales by Category
4. Added slicer (filter) for Category and Region.
5. Used color highlights to emphasize top-performing segments.
